**Related Plan**: 2026-01-30-golang-port-epics-plan.instructions.md

## Summary

Implementation of User Stories 1.1.1, 1.1.2, 1.1.3, and 1.4.2 for the Microsoft Agent Framework Go port:

* User Story 1.1.1: Initialize Go Module
* User Story 1.1.2: Configure CI Pipeline

## Additional or Deviating Changes

* OpenTelemetry pinned to v1.33.0 instead of latest
  * Reason: Latest versions (v1.39.0) have transitive dependencies requiring Go 1.24+, which exceeds the Go 1.22+ minimum requirement specified in the port plan
* Created observability package with minimal implementation
  * Reason: Needed to ensure OpenTelemetry dependencies are actually required by the module (go mod tidy removes unused dependencies)
